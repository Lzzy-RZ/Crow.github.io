文件下载(Unsafe File Download)

工具:curl

环境:本地 Pikachu 靶场

内容:验证网页文件下载漏洞存在

原理:网站把“用户给的文件名”直接拿过去读,没有进行限制,类似于文件包含,区别是文件下载是把文件内容给你,而文件包含是打开文件并交给php解析.

1,进入本地靶场

2,先下载一个科比看看路径(找下载的入口)

发现路径没变

3,查看下载链接指向哪儿

我们在终端用 curl -s 'http://127.0.0.1:8080/vul/unsafedownload/down_nba.php' | grep -oE 'href="[^"]+"' | head -n 20 查看

前面全是 CSS，球员链接应该在页面后面。

4,换成看尾部

找到了下载口execdownload.php?filename=kb.png

5,验证漏洞存在

返回200,文件内容也对的上

## 目录结构

这个仓库装的是 `hexo generate` 生成的**静态站点**，不是 Hexo 源码。根目录主要是 `index.html`、`404.html`、`local-search.xml`，以及 `about/`、`archives/`、`categories/`、`tags/`、`links/`、`css/`、`js/`、`img/`、`xml/` 等目录。站点源码（`_config.yml`、`source/_posts/`、`themes/`）在本地维护，不在这个仓库里。

## 本地命令

在博客根目录执行：

```bash
hexo new "文章标题"   # 新建文章
hexo s                # 本地预览 http://localhost:4000

hexo clean            # 清缓存
hexo g                # 生成静态站点
hexo d                # 部署到 GitHub Pages
```

### Directory Structure

This repository contains the **static site generated by `hexo generate`**, not the Hexo source. The root holds `index.html`, `404.html`, `local-search.xml`, and directories such as `about/`, `archives/`, `categories/`, `tags/`, `links/`, `css/`, `js/`, `img/`, `xml/`. The Hexo source (`_config.yml`, `source/_posts/`, `themes/`) is maintained locally and is not part of this repository.

### Local Commands

Run these from the blog root:

```bash
hexo new "post title"   # create a post
hexo s                  # preview at http://localhost:4000

hexo clean              # clear cache
hexo g                  # generate
hexo d                  # deploy to GitHub Pages
```
